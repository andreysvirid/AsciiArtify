# Concept

## 🎯 Ціль
Сформувати бачення інфраструктури для проєкту AsciiArtify.

## 🔧 Ідеї
- Використати **k3d** для локального швидкого стенду.
- Використати **Prometheus + Grafana** для моніторингу.
- Логи збирати через **Loki** або **Fluent Bit**.
- CI/CD інтегрувати з GitHub Actions.
- Розгортання реалізувати за допомогою GitOps (Flux або ArgoCD).

## ✅ Результат
Є концепція майбутньої інфраструктури та план переходу до PoC.
